## Reading guide

- **LIVE** = the daily-brief regen and routine sessions depend on it; if it broke, you'd notice today.
- **PARTIAL** = the canonical artifact exists but a key piece is missing — empty target table, missing card, prose-only protocol, etc.
- **DESIGNED** = a docx or markdown spec exists in the repo; no code, no data.
- **NOT BUILT** = mentioned in strategy/intelligence docs, no implementation, no concrete spec to point at yet.

When in doubt, downgrade. A "LIVE" claim is a contract; promote up only when the thing has actually been exercised against real data.
