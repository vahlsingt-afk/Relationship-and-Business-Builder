## How this Circle progresses
1. You add a target account with a one-line "why fit."
2. The system finds the named tech leader (LinkedIn lookup) and populates them in the table.
3. The system queries `baseline_index.json` for connections at that company OR connections to that named leader (1st/2nd-degree) and proposes the best inroad.
4. The intro broker comes from `intro_brokers.md` if available; otherwise from candidate brokers in the relevant domain Circle.
5. Status moves: `target` → `inroad-identified` → `intro-requested` → `meeting-set` → `won` / `lost` / `parked`.
